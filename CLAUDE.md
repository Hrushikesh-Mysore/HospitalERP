# Hospital Management Dashboard
- 90-minute hackathon; scored on technical complexity, UI quality, ease of use
- Stack: React, Vite, Tailwind v4, framer-motion, react-router-dom, recharts, lucide-react; Express in /server; no database
- Run: `npm run dev:all` (frontend :5173, backend :3001)
- Structure: src/components/ui, src/components/layout, src/pages, src/data, src/lib, server/routes, server/data, server/middleware
- Design: light theme, teal accent, rounded-2xl cards, 8px grid, mobile-first

## Rules
- Fake data only, never real patient data
- Validate all input with zod; never commit .env
- One component per file; keep responses short; edit only files needed
- 80% of effort on UI polish

## Workflow
- Read PLAN.md to see which phase is next; work on ONE phase only
- Mark finished tasks [x] in PLAN.md; commit with git after each phase
